# MpxHR "Ask AI" assistant

A small serverless function (`ask.js`) that answers website visitors' questions with Groq, using the site's own
content as reference. The Groq key stays on the server. It is never in the browser or in this repository.

How it works: the chat box on the site posts the question to `/api/ask`. The function picks the few most relevant
items from `_kb.js` (features, FAQ, tutorials, plans, release notes and the user guide, generated by `node build.js`),
sends them to Groq with the question, and returns the answer.

## Turn it on (one time, about 5 minutes)

1. In Vercel choose **Add New > Project** and import the GitHub repo that holds the website
   (`mithleshprasad/MpxHR-Enterprise`). Leave the build settings empty (no framework, no build command).
2. Open **Settings > Environment Variables** and add `GROQ_API_KEY` with your Groq key. Redeploy.
3. Optional variables:
   - `ALLOWED_ORIGINS`: comma separated list of sites allowed to call the function. Default:
     `https://mithleshprasad.github.io,http://localhost:3000,http://localhost:5173`.
     Add your Vercel address or your own domain if you serve the site from there.
   - `GROQ_MODEL`: default `openai/gpt-oss-20b`.
4. In `site-config.js` set `aiEndpoint` to the full address, for example
   `https://your-project.vercel.app/api/ask`, then run `node build.js` and publish the site again.

Until `aiEndpoint` is set the assistant button is not shown.

## Limits and safety

- Questions are limited to 300 characters; the last 4 chat messages are sent for follow-ups.
- 15 questions per visitor (by IP) every 10 minutes. This counter lives in each serverless instance's memory, so it
  is a speed bump, not a hard limit. Watch your Groq usage; the free tier has a tokens-per-minute cap.
- Only the origins in `ALLOWED_ORIGINS` can call the function from a browser.
- The assistant is told to answer only about MpxHR and to say when it is unsure instead of inventing prices.

## Update the knowledge

Run `node build.js` after changing the site content or the user guide. It rewrites `api/_kb.js`. Commit the result.
